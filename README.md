# ChatGPT 与 Codex 中文指南：套餐选择、额度与常见问题

面向个人用户，帮助你在订阅或升级前，先判断需要什么功能、遇到了哪种用量限制，以及等待还是付费更合适。本文以 Codex 使用场景为主；普通 Chat 对话的模型与消息限制须另查对应说明。

**资料核实：2026-10-20。** 功能、价格与开放范围会变化，购买前请重新查看官方原文和本人账号。

**维护者与商业关联：** 本指南由 GPT-Duo（AI DUO）维护。GPT-Duo 同时经营 AI 订阅相关服务；文中的 GPT-Duo 延伸阅读链接属于维护者自有资料，页面含商业商品信息。本仓库是独立维护的中文资料，不是 OpenAI 官方文档。

## 先用一分钟判断

| 你现在的情况 | 建议先做什么 |
| --- | --- |
| 还没开始用，不知道需要哪档 | 用现有账号做一个真实的小任务，记录缺少的功能或用量提示 |
| 任务能等到恢复 | 先看账号显示的恢复时间，再安排下一次任务 |
| 临时有交付，现有额度不够 | 比较账号实际提供的补充选项、费用和适用条件 |
| 连续几周都被打断 | 记录常用模型、任务规模和额外支出，再比较套餐 |
| 付费后仍报错，或模型没有出现 | 先核对账号、工作区、登录方式和报错原文，再决定下一步 |

这里的建议是选择方法，不是按使用频率强制划档。每天做几次小修改，与一次运行大型项目，所需用量可能很不一样。

## 1. 先分清订阅与 API 计费

Codex 的登录方式影响计费和权限：用 ChatGPT 登录，使用适用的订阅权益；用 API key 登录，按 API 体系计费。桌面应用、CLI 和 IDE 扩展支持这两类本地登录，Codex Cloud 要求 ChatGPT 登录。API key 用量不从 ChatGPT 套餐 credits 中扣除。

来源：[官方 Authentication](https://learn.chatgpt.com/docs/auth)。

如果你要做自动化接入，先确认实际采用哪种认证和账单，再比较成本。不要只看到“有 Plus／Pro”就假定所有工具都能直接使用订阅。

## 2. 个人套餐的价格与入口

下表摘记官方美元月价，用于辨认档位。实际结算金额及条款请查看自己的购买页面。

| 套餐 | 官方月价 | Codex 范围摘要 |
| --- | --- | --- |
| Free | $0 | 桌面应用的 GPT-6 Luna Standard，受开放进度影响 |
| Go | $8 | 桌面应用的 GPT-6 Luna Standard，受开放进度影响 |
| Plus | $20 | 更广的模型与客户端范围，包含云端相关功能 |
| Pro | $100／$200／$500 | 在 Plus 基础上按需要比较 Pro 档位 |

组织可另查 Business、Enterprise、Edu；团队权限、管理和数据要求也应纳入选择。

来源：[官方 Pricing：套餐和功能范围](https://learn.chatgpt.com/docs/pricing)。

本文不按月费比例推算任务数。需要中文扩展对照时，可参考维护者整理的 [ChatGPT／Codex 各套餐额度对照](https://www.gpt-duo.com/blog/codex-limits-by-plan)；其中的 GPT-Duo 商品名称、人民币售价和办理条件应与官方套餐分开看。

正在比较 Go 与 Plus，可继续阅读 [Go／Plus 怎么选：按任务和功能核对](docs/chatgpt-go-vs-plus.md)，区分日常聊天、工具与 Codex 的选择。

## 3. Codex 额度不够／usage limit：先查哪一项

官方定价页说明：Plus 的参考消息量对应五小时窗口，周限制也可能适用；Pro 当前没有五小时限制，仍须查看账号用量。模型、上下文和工作量会影响消耗，本地与云端共享套餐用量；Work 与 Codex 也共享用量。参考消息数不是固定保证。

查看当前用量和恢复时间，可从客户端的用量页面进入；CLI 可输入 `/status`。以当前账号显示为准。

来源：[官方 Pricing：Usage limits 与用量入口](https://learn.chatgpt.com/docs/pricing#frequently-asked-questions)。

看到 **You've hit your usage limit** 等用量提示时，建议记下四项信息：

1. **提示指向什么：** 短窗口、周用量、某个模型，还是权限／连接问题。
2. **何时恢复：** 记录页面显示的具体时间和时区，避免凭“过了午夜”猜测。
3. **哪里发生：** 当前账号、个人或组织工作区、桌面／CLI／IDE／Cloud。
4. **还差什么工作：** 剩余任务、截止时间，以及是否能拆小或稍后完成。

不要把“额度不足”“订阅到期”和“服务异常”合并成同一种问题；也不要只看一个剩余百分比就判断所有功能可用。

需要按提示逐步定位时，阅读 [Codex 用量上限排查](docs/codex-usage-limit.md)：先核对身份和限制，再整理恢复时间、异常现象及反馈资料。

## 4. 等待、补充用量，还是升级

先比较任务能否等待，再比较当前账号提供的选项。官方说明 Plus／Pro 达到限额后可购买额外 credits；具体购买条件及选项须看账号页面。[官方说明](https://learn.chatgpt.com/docs/pricing#frequently-asked-questions)

| 选项 | 决定前核对 |
| --- | --- |
| 等自然恢复 | 恢复时间能否满足截止日期；其他限制是否仍会影响任务 |
| 购买 credits | 价格、适用功能、扣费规则；为剩余工作设一个支出上限 |
| 升级套餐 | 所需功能、更高用量、当前订阅的调整方式和最终结算金额 |

具体购买选项取决于账号。付款前先阅读账号中的说明，不凭他人的截图推定自己有同样入口。

一个可执行的比较办法：记录一至两周里任务被打断的时间、临时补充支出和实际延误。只有持续需求明确，才把升级差价放进比较；“一周撞限两次”本身不能证明哪种方案更划算。

需要进一步梳理场景时，可阅读维护者的 [Codex 额度不够时，如何比较等待与升级](https://www.gpt-duo.com/blog/codex-wait-or-upgrade)。该文含维护者商品信息；付款条件和官方用量规则分别核对。

## 5. 模型、推理与速度也会改变选择

官方模型说明建议：聚焦、重复的任务可考虑 Luna；复杂工作可在账号与客户端支持时考虑 GPT-6.1 Sol。推理强度提高可能帮助复杂任务，也会增加时间和 token 消耗。可以先用默认设置，再根据结果调整。

来源：[官方 Models](https://learn.chatgpt.com/docs/models)。

速度模式也影响用量：当前支持模型的 Fast 对套餐内用量按 Standard 的 2.5 倍计算，对购买 credits 按 2 倍计算；Ultrafast 的对应倍率为 8 倍和 6 倍。它们是用量或费率倍率，不是任务完成时间的保证。

个人 Pro 档中，当前 Pro $500 提供 Ultrafast；符合条件的 Enterprise／Edu 也可使用。购买 credits 不会让其他自助套餐获得该模式。API key 登录使用 API 计价，不能套用 ChatGPT credits 倍率。

来源：[官方 Speed：支持范围与计费](https://learn.chatgpt.com/docs/agent-configuration/speed)。

在考虑花更多钱之前，可以先尝试：

- 写清本次目标、需要处理的文件与验收方式。
- 把可独立完成的小任务拆开，减少与当前任务无关的材料。
- 选择能完成任务的可用模型，观察结果再决定是否提高推理或速度。

这些做法用于控制工作范围，不承诺固定节省比例。

## 6. 常见问题

**买 Pro 就能无限用 Codex 吗？**

不能据此理解为无限用。查看账号的适用限额与剩余量；当前没有五小时限制，不等于所有限制都消失。[官方用量说明](https://learn.chatgpt.com/docs/pricing#frequently-asked-questions)

**为什么相同套餐，别人看到的模型和我不同？**

先核对模型的开放范围、客户端与工作区权限。官方说明选择新模型不会授予该模型的访问权限。[官方 Models](https://learn.chatgpt.com/docs/models)

**已经付费，为什么仍出现 usage limit？**

先分别核对套餐状态、用量恢复时间与实际登录账号，并记录报错。订阅有效期间也要看适用用量限制；通过第三方办理时，结果不明确应先核实原订单，再决定是否付款。[官方用量说明](https://learn.chatgpt.com/docs/pricing#frequently-asked-questions)

**商家写的“5X／10X／25X”能当成官方固定额度吗？**

不能。商家商品标签、官方套餐、实际功能和账号用量需要逐项对应。尤其要核对续费是否累计、是否覆盖剩余时间，以及新周期如何起算。
