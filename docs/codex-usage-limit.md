# Codex 用量上限排查：看到 usage limit 后先查什么

看到 `You've hit your usage limit`，先保留报错，再核对它对应的账号、工作区和限制。一个用量数字不足以解释所有报错，也不能单凭这句话认定订阅到期。

**资料核实：2026-10-20。** 以下顺序是维护者根据官方资料整理的排查建议，不是对具体账号原因的诊断；入口与开放范围以当前客户端、账号和官方说明为准。

**维护者与商业关联：** 本文由 GPT-Duo（AI DUO）维护。GPT-Duo 同时经营 AI 订阅相关服务，文末自有文章含商业商品信息。本指南不是 OpenAI 官方文档。

## 1. 先记录发生了什么

不要先更改套餐。用一分钟记下：

| 记录项 | 需要看清的内容 |
| --- | --- |
| 报错 | 完整文字；是否提到用量、具体模型、权限、登录或连接 |
| 发生位置 | 桌面端、CLI、IDE 扩展还是云端；个人或组织工作区 |
| 当前任务 | 是否仍在运行、还剩什么工作、截止时间 |
| 用量页 | 限制名称、百分比表示已用还是剩余、恢复时间及时区 |

建议把“任务是否完成”和“后续请求能否继续”分别核对。不要仅凭报错就重复提交同一项工作。

## 2. 确认看的确实是同一账号

在报错客户端的个人菜单中确认账号和工作区，再与查看用量的页面对照。浏览器登录身份不能代替 CLI 的身份检查。

CLI 可运行：

```sh
codex login status
```

它用于查看当前认证方式。ChatGPT 登录使用适用的订阅权益；API key 使用 Platform 的 API 计费，不扣 ChatGPT 套餐 credits。API key 场景应核对对应项目和账单，不能用 ChatGPT 订阅剩余量代替。

依据：[官方 Authentication](https://learn.chatgpt.com/docs/auth)。

## 3. 找出实际触及的限制

打开账号的用量页面；CLI 可用 `/status` 查看状态与限额。`codex login status` 和会话中的 `/status` 用途不同，二者都不是重置命令。[官方命令说明](https://learn.chatgpt.com/docs/developer-commands)

Work 与 Codex 共享用量，本地与云端也共享套餐用量。Plus 需关注短窗口及可能适用的周限制；Pro 当前没有五小时限制，仍应看实际用量。消耗取决于模型和任务，参考消息量不是固定保证。[官方 Pricing](https://learn.chatgpt.com/docs/pricing#frequently-asked-questions)

| 当前页面显示 | 建议下一步 |
| --- | --- |
| 某个适用窗口已用完 | 记录这一项的恢复时间；不要用另一项的剩余量推定已经恢复 |
| 提示指向某个模型或权限 | 转到下一节，核对模型访问与工作区 |
| 数字有余量，但提示不明确 | 保存数字旁的标签和完整报错，继续核对身份与其他限制 |
| 找不到用量或恢复时间 | 保留客户端和版本信息，使用该客户端提供的帮助或反馈入口 |

## 4. 仍有余量却报错，依次核对

1. **身份是否一致：** 报错客户端、用量页和订阅是否对应同一账号及工作区。
2. **读到的是哪项数字：** 套餐用量、上下文容量和某个模型的提示应分别记录，不能只写“还剩 30%”。
3. **模型是否开放：** 检查该模型在当前产品、客户端和工作区是否可用。选中模型本身不会授予访问权限。[官方 Models](https://learn.chatgpt.com/docs/models)
4. **是否伴随另一类异常：** 登录失败、网络连接或工作区权限问题，按实际提示继续排查，不直接归因于额度。
5. **状态是否变化：** 可重新打开用量页，记录前后差异。这是核对步骤，不保证刷新、重启或重登能够修复问题。

新开会话或切换模型不应被当作恢复共享用量的办法。若改用其他已开放模型，也要先确认实际适用的限制。

## 5. 再决定等待还是比较其他选项

先把页面显示的恢复时间与任务截止时间放在一起看。任务能等，就安排稍后继续；任务不能等，再比较本人账号实际提供的选项、费用及适用范围。不要先付款，再验证是否能解决原问题。

等待、补充用量与升级的比较见[指南首页第 4 节](../README.md#4-等待补充用量还是升级)。本文不展开重置卡、即时重置或付款异常的完整流程。

## 6. 仍无法解释时，整理一份问题记录

下面是便于说明问题的建议清单，不是官方必填表单：

```text
客户端及版本：
登录方式与工作区类型：
套餐、模型及速度设置：
发生时间与时区：
报错原文：
用量页的限制名称和恢复时间：
已尝试的操作及前后结果：
```

可按客户端提示使用反馈入口；CLI 提供 `/feedback`，桌面反馈可选择附带会话。提交前检查截图、会话和日志，遮去密码、API key、令牌及付款资料；公开 Issue 不提交个人账号明细。诊断资料是否附带，由你检查后决定。[官方反馈与日志说明](https://learn.chatgpt.com/docs/reference/troubleshooting)、[CLI 命令说明](https://learn.chatgpt.com/docs/developer-commands)

## 常见问题

**刚付费仍触限，要再买一次吗？**

先分别确认订阅是否生效、当前登录身份、实际触及的限制与恢复时间。原付款或办理结果不明确时，先向原购买渠道核对原记录。

**能按别人截图里的时间等待吗？**

请使用自己账号、当前限制对应的恢复时间，并确认时区。截图中的其他账号不能替代本人的用量页面。

**排查后一定能恢复吗？**

本文帮助定位需要核实的信息，不承诺恢复、额外额度或补偿。规则变化时，应重新查看相关官方资料。
