## 怎样核对自己的账号

打开本人账号的用量页面，确认账号、工作区、限制名称、百分比旁的“已用／剩余”标签和下一次恢复时间。一次窗口恢复，不等于所有限额均恢复；别人的截图也不能代替本人账号状态。

自动／全局重置、可保存的 banked reset 和付费即时重置是不同机制。自动重置直接作用于公告选择的用量，不会因此多出一张保存卡；同一套餐或以前收到过重置，都不能证明本次一定符合资格。具体规则见 [OpenAI 官方重置说明](https://help.openai.com/en/articles/20001498-how-resets-work-in-codex)。未来活动没有保证的固定时刻表。
